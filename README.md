每道练习卡片下方都有“题目资料”：CSV 可直接预览前 20 行，XLSX/DOCX/IPYNB/图片可下载后用本地工具处理。5 个 ONNX 模型放在 GitHub Release 中，避免超过普通 Git 文件限制。题目与答案的 40 题 / 478 空双重核验记录见 [`AUDIT-REPORT.md`](AUDIT-REPORT.md)。

## 启动

在本目录运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://127.0.0.1:4173>。

## 使用方式

1. 首页点击“填空模拟”，或进入“开始训练”后选择“填空题”（覆盖全部 40 道题）。
2. 每题逐空填写，点击“提交并批改”；系统会逐空显示得分、错点和参考答案。
3. 点击“会了 / 模糊 / 不会”记录掌握状态；错题会进入“错题复盘”。
4. 1.1、2.1、2.2、3.2 的空位按资料 Notebook 代码、文件名和评分点拆分；1.2 的答题卷按独立单元格拆分；3.1 按原始 DOCX 每个实际空单元格拆分（同一行的亮度/色温、功能列表、影响因素等均是独立输入框）；4.1–4.2 的空位按 DOCX 下划线或原文答案拆分。代码空可填写完整代码，系统按关键语句批改。
5. 页面中的“核对版完整参考答案”优先显示可运行、可提交的写法；原资料中的 OCR 错字和参考代码冲突会在题目卡片中明确标注，并保留原文变体。2.1.3 另有两个“不计入原题空位数”的题面补充检查：`IncomeToDebtRatio`、`MonthlyIncome`。
6. 进度只存于当前浏览器的 localStorage，不会上传到第三方网站。
7. 带 Notebook、CSV 或 XLSX 的题目会显示“Python 实操”区。首次运行从 CDN 加载 Pyodide；“加载本题数据”会把原始素材挂载到浏览器本地，代码输出和生成文件可直接下载。Python 运行在浏览器沙箱内，不支持服务器端 shell、ONNX Runtime 或大型原生依赖；3.2 模型题仍按下载模型后用本地环境/ONNX Runtime Web 练习。

题目卡片是训练提示和动作骨架，不替代原始 Notebook、DOCX、数据集或考场文件要求；真正练习仍要回到下载的资料中实际运行并生成交付文件。PDF 提取文字可能保留少量 OCR 空格或符号误识别，正式操作以原 PDF、Notebook 和 DOCX 为准。
